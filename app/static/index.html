About this prototype

The current retrieval baseline uses lexical token matching, not vector embeddings. If GEMINI_API_KEY is configured, retrieved passages are sent to Gemini with instructions to answer only from those passages. Verify generated answers against source excerpts. Documents are stored in memory and cleared when the server restarts.
